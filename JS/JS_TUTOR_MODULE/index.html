Topic Title

What is JavaScript?

The Brain of the Web

Imagine your website as a human body:

HTML

The Skeleton. It gives structure (bones) to your content.

CSS

The Skin & Style. It makes the body look good (clothing, appearance).

JavaScript

The Brain & Muscles. It makes the body move, think, and react.

Without JavaScript, the web is static posters. With it, the web becomes an interactive playground.

logic.js
const button = document.querySelector('.btn');
 
// This is the "Brain" reacting to a click
button.addEventListener('click', () => {
document.body.style.backgroundColor = '#0a0a12';
alert('JavaScript is alive!');
});
